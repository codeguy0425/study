# 普通話口試說話題目溫習模組 (Putonghua Oral Prep Module)

本目錄 (`/pth`) 包含**中一級普通話科口試說話題目**的完整自主溫習與朗讀示範工具。此模組旨在幫助學生練習普通話口試的一分鐘說話，並提供標準發音示範、拼音對照及自主計時功能。

---

## 📂 檔案清單與結構

* 📄 **`scripts.html`**：模組的主網頁。提供流暢、互動的口試說話練習介面。
* 📄 **`print.html`**：列印溫習版。提供極簡、大氣、適合直接列印或匯出為 PDF 的排版。
* 📂 **`templates/`**：包含 `scripts_template.html` 與 `print_template.html` master 模版網頁，用作編譯來源。
* 📂 **`drafts/`**：各題目優化後的純文字草稿 (`topic1.txt` - `topic6.txt`)。
* 📂 **`audio/`**：
  * `drafts/`：由 Windows 語音 API 合成的標準示範錄音草稿音訊。
  * `published/`：已發佈的標準音訊備份。
* 📂 **`src/`**：
  * ⚙️ **`build.py`**：自動化編譯腳本。自動掃描草稿、推廣音訊、高優先級上下文多音字組（`WORD_OVERRIDES`）處理、防漂移同步更新模版與 production 網頁，並自動遞增 PWA 緩存。
  * ⚙️ **`generate_audio.py`**：利用 Windows PowerShell Speech Synthesis 離線合成標準普通話示範音訊。
  * ⚙️ **`analyze_timing.py`**：音訊時長與語速分析腳本，確保每題說話時長精確落在 **55.0 至 65.0 秒** 的黃金區間。
* 🎵 **音訊示範檔 (`topic1.wav` - `topic6.wav`)**：部署於生產根目錄的 6 個題目示範錄音。
* 🖼️ **`401548.jpg`**：背景/介面視覺設計素材。

## 🌟 核心功能特色

1. **互動拼音標註 (`<ruby>` 標籤)**
   * 每個漢字上方均精準標註對應的普通話拼音。
   * 設有**「拼音開關」**按鈕，點擊即可切換顯示或隱藏拼音，方便進行自我測試（遮讀與視讀切換）。

2. **自訂音訊播放器 (Custom Wave Player)**
   * 支援流暢的示範朗讀播放。
   * 具備播放/暫停按鈕、即時進度條與時間顯示（當前播放時間 / 總時長），並支援點擊進度條進行快進或倒退。

3. **1 分鐘口試自主練習計時器 (1-Min Practice Timer)**
   * 完美模擬真實考試的 **1 分鐘說話限制**。
   * **計時規則提醒**：根據普通話口試標準，發言時間少於 30 秒者，內容得分上限為 5 分（滿分 10 分）。
   * **智慧提示系統**：
     * 若計時暫停且說話**不足 30 秒**，會跳出 <span style="color: #be123c; font-weight: bold;">⚠️ 警告提示</span>，提醒內容不足。
     * 若說話**超過 30 秒**，會跳出 <span style="color: #047857; font-weight: bold;">🎉 成功提示</span>，確認已過安全線，並顯示當前說話秒數。

4. **「列印溫習版」導航 (Print Version Navigation)**
   * 網頁頂部 header 設有專屬的 **「列印溫習版」** 快捷連結，並配有直觀的印表機圖示。
   * 點擊即可無縫跳轉至專為紙質列印/PDF 匯出設計的 `print.html` 網頁。

5. **「全螢幕」沉浸式行動體驗 (Mobile-Optimized Viewport)**
   * 行動端視口精細優化，將外圍間距縮減至 `p-2.5`、卡片內邊距縮減至 `p-3.5`。
   * **獨立滾動視窗擴大**：將手機端的範文顯示區域最大高度由 300px 擴大至 **`460px`**，並將手機字體放大至 **`text-xl`**。
   * 為學生提供幾乎免滾動、高對比度的行動端「全螢幕」沉浸式視讀與遮讀練習體驗。

6. **PWA 離線支援 (Offline Capability)**
   * 已在根目錄的 `sw.js` 中註冊並預先快取 (`PRE_CACHE`) 本模組的 `scripts.html` 網頁。
   * 即使在無網路環境下（如考場外或地鐵上），亦能順暢加載和進行溫習。

## 🛠️ 開發與技術堆疊

* **結構與佈局**：HTML5 語意化標籤。
* **樣式與美化**：使用 **Tailwind CSS (v4)** 進行現代化、響應式（Mobile-First）及極簡雅緻的琥珀色調 (`amber/slate`) 介面設計。
* **字型**：載入 Google Fonts 的 **Inter** 與 **Noto Serif TC (思源宋體)**，提升範文與拼音在不同裝置上的閱讀體驗。
* **邏輯控制**：純原生 JavaScript 實現音訊同步、計時器狀態機及拼音切換 DOM 操作。
